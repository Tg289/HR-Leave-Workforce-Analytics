# User Stories

## US-01: HR Overview

**As an HR manager, I want to see workforce KPIs in one place so that I can quickly understand the current workforce picture.**

### Acceptance Criteria
- Active headcount is displayed.
- Department distribution is available.
- Leave approval rate is displayed.

## US-02: Department Analysis

**As a department manager, I want to compare leave and attendance patterns across departments so that I can identify workforce availability issues.**

### Acceptance Criteria
- Leave days can be grouped by department.
- Average attendance can be compared by department.
- Results can be interpreted without manual calculations.

## US-03: Leave Trend Analysis

**As an HR executive, I want to view monthly leave trends so that I can identify periods with higher workforce absence.**

### Acceptance Criteria
- Monthly leave totals are available.
- Leave types can be compared.
- Pending requests are distinguishable from approved requests.
